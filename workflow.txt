Here is how to clean up the deprecation warning and fix the zero score on answer_relevancy.

Why answer_relevancy Scored 0.0000
RAGAS calculates answer_relevancy by asking the judge model (mistral) to generate 3 candidate questions based only on your generated answer, then embedding those candidate questions and taking the mean cosine similarity against the user's original query.

Local 7B models often format the internal RAGAS question-generation prompt output slightly off-spec (e.g., adding conversational prefixes or missing specific JSON delimiters), causing RAGAS to fail parsing the generated questions and default to 0.0.

FIX:
Step 1: Fix Deprecation Warning
Install the modern langchain-huggingface package:

Bash
pip install -U langchain-huggingface
